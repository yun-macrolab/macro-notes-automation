# 3~5분 시연 대본

실행 화면: http://127.0.0.1:8765

본인이 이해한 표현으로 바꿔 읽는다. 아직 이해하지 못한 구현을 직접 설계했다고 말하지 않는다. 이 파일은 녹화 대본이며 영상 파일은 아니다.

## 0:00~0:40 · 업무 문제

“개인 채권 리서치에서 뉴스를 정리하고 주간 판단의 초안을 만드는 반복 업무를 다룹니다. 지표와 전망을 구분하고, AI가 만든 초안을 사람이 검토하는 흐름을 만들었습니다. 오늘 보여드릴 자료는 모두 가상 예시이며, 분류와 초안은 미리 작성했습니다. Python의 검증·집계·저장 단계는 지금 실제로 실행합니다.”

화면: 기본 초안 선택 → 새 시연 실행. 왼쪽 원문 8건, 오른쪽 분석 7행을 가리킨다.

## 0:40~1:20 · 숫자보다 근거

“물가 지표와 그 지표를 해석한 하우스 의견을 둘 다 더하면 같은 정보를 중복 반영할 수 있습니다. 그래서 의견은 따로 보여줍니다. 정책 점수는 매파 발언만으로 정하지 않고 시장 프라이싱과 경로 전망의 차이로 계산합니다. 필요한 수치가 없으면 초안의 점수를 버립니다.”

화면: 기본 초안의 글로벌 정책 점수 0과 근거 없음 표시. 원래 고정 초안에는 -1.5가 있었음을 설명한다.

“다만 현재 규칙은 계산 불가도 0으로 기록하므로 실제 중립과 구분해야 합니다. 이 화면은 근거 수치 미입력 행 수를 별도로 표시합니다. 후속 설계에서는 결측 상태를 점수와 분리하는 방법도 검토할 수 있습니다.”

## 1:20~2:10 · 사람의 수정 보존

화면: 글로벌 펀더멘털 검토 점수 +1.5 → 수정값 저장 → 재실행·보존 확인.

“자동 초안은 -1이었지만 검토자가 +1.5로 바꿨다고 가정하겠습니다. 다시 실행해도 +1.5가 유지됩니다. 마지막 자동값과 현재값이 다르면 사람이 바꾼 것으로 감지하고, 그 칸을 잠급니다. 같은 값을 저장하는 것은 변경으로 감지하지 못한다는 한계도 있습니다. 전체 채점 확정 기능은 이 데모에 넣지 않았습니다.”

화면: 보호 1칸, 뉴스 8건 유지, 실행 로그 human_review와 draft_apply를 확인한다.

## 2:10~2:50 · 오류 입력

화면: 점수 범위·단위 오류 → 새 시연 실행.

“고정 초안의 0.7은 0.5로, -3은 -2로 보정됩니다. 이 규칙은 모델에게 부탁하는 문장이 아니라 Python 코드에서 실행됩니다. 다만 이런 형식 검증으로 뉴스 해석이 옳다는 것까지 증명되지는 않습니다.”

시간이 남으면 정책 갭 +60bp 시나리오를 실행해 정책 듀 +2, 커브 -2를 보여준다.

## 2:50~3:40 · 검증과 기여

화면: 검증과 설명 메뉴 → 실제 측정된 검증표.

“이 표는 가상 입력에서 규칙과 보존 동작을 테스트한 결과입니다. LLM 정확도나 투자 수익률 테스트는 아닙니다. 본 프로젝트에는 AI 코딩 도구의 도움을 받았습니다. 제가 실제로 담당한 부분은 [본인이 확인한 업무 정의·규칙·운영·검토 범위]이며, 지금 직접 설명하거나 수정할 수 있는 부분은 [직접 수행한 내용]입니다.”

대괄호 부분은 본인이 채우기 전에는 제출용 문구로 사용하지 않는다.

## 3:40~4:30 · 다음 단계

“현재는 단일 사용자 로컬 시연입니다. 이후 입력 검증 함수를 직접 작성하는 것부터 시작해 FastAPI와 DB 저장, LLM 결과 평가, 권한 통제, 작업 재시도 순서로 확장하겠습니다. 기술을 추가할 때마다 실패 사례를 먼저 정하고 검증 결과를 남기겠습니다.”

## 녹화 체크

# 실행 안내

[프로젝트 소개로 돌아가기](../README.md)

아래 경로와 명령은 저장소 루트를 기준으로 합니다.

## 지금 시작

1. Windows에서 `Start-Demo.bat`을 더블클릭합니다. 백그라운드 서버와 브라우저가 열립니다.
2. `초안 검토`에서 기본 시나리오의 **새 시연 실행**을 누릅니다.
3. 검토 점수 **+1.5 → 수정값 저장 → 재실행·보존 확인**을 누릅니다.
4. 뉴스 8건 유지, 점수 +1.5 유지, 수정 보호 1칸을 확인합니다.

주소: http://127.0.0.1:8765

서버 종료: `Stop-Demo.bat`. 브라우저를 닫아도 서버는 종료되지 않습니다.

## 다른 PC에서 실행

Python 3.10 이상이 필요합니다. 실제 검증 환경은 Python 3.13.2 / openpyxl 3.1.5입니다. 데모 폴더에서:

```powershell
python -m pip install -r requirements.txt
python -X utf8 app.py
```

8765 포트가 사용 중이면 `python -X utf8 app.py --port 8766`으로 실행하고 http://127.0.0.1:8766 으로 접속합니다. `localhost` 대신 `127.0.0.1`을 사용합니다. 직접 실행한 서버는 해당 터미널에서 Ctrl+C로 종료합니다.

Windows에서 Python 3.13을 기본 위치에 설치했지만 PATH에서 python을 찾지 못하면:

```powershell
& "$env:LOCALAPPDATA/Programs/Python/Python313/python.exe" -X utf8 app.py
```

의존성 설치 후에는 API 키나 외부 서비스 연결 없이 실행합니다.

## 메뉴와 기능

| 메뉴 | 할 수 있는 일 |
|---|---|
| 초안 검토 | 시나리오 실행, 원문 검색·유형 필터, 자동 초안과 검토값 비교, 점수 수정, 재실행, Excel 다운로드, 이력 조회 |
| 검증 기록 | 실제 실행한 동작 검사 결과와 검증 범위 확인 |

원문 필터는 화면에 보이는 기사만 바꿉니다. 점수 집계는 계속 가상 뉴스 8건을 기준으로 합니다. 수정값 저장 뒤에는 `재실행 대기`, 재실행하여 변경값이 보존되면 `수정값 보존 확인`이 표시됩니다. 상단 시나리오 선택은 다음 실행에 적용되며, 지금 보고 있는 시나리오는 `현재 결과`에 별도로 표시합니다.


## 산출물

- `docs/설계노트.md`: 구조·재사용 범위·동시성·보안·미구현 항목
- `evidence/검증결과.md`, `evidence/results.json`: 동작 검사 결과와 엔진 해시
- `runtime/<실행ID>/demo.xlsx`: 해당 실행의 합성 워크북
- `runtime/<실행ID>/trace.jsonl`: 단계별 실제 실행 기록
- `runtime/history.sqlite3`: 실행별 시나리오·시간·상태. 재시작 후에도 보존

`engine/`은 복사 시점의 코드 스냅샷입니다. 운영 프로젝트가 바뀌어도 자동 동기화하지 않습니다.

## 검증 실행

```powershell
python -X utf8 verify.py
```

임시 합성 워크북으로 정상 처리·정책/TP 규칙·범위 보정·의견 제외·수정 보존·묶음 중복 방지·입력 거절·로컬 API 경계를 확인하고 `evidence` 결과를 갱신합니다. 이 테스트의 통과율은 LLM 정확도나 투자성과가 아닙니다. 데모 실행시간도 업무시간 절감률이 아닙니다.

## 알려진 제한

- 단일 사용자·로컬 시연입니다.
- 로컬 HTTP 서버는 작업 중 다른 요청이 대기합니다. 큐·분산 잠금은 없습니다. 서버를 두 개 실행해 같은 runtime을 함께 쓰지 마세요.
- 이 시연은 뉴스 분류 단계를 고정 초안(data/sample.json)으로 대체했습니다. 원본 파이프라인에서는 AI가 분류하며, 실시간 수집은 원본에도 없습니다(원문 수동 투입).
- 수정 보존은 기존 엔진의 값 비교에 의존합니다. 자동값과 같은 값을 저장하면 변경으로 감지되지 않습니다.
- 정책/TP 수치가 없으면 0점 처리되며 합계가 중립 쪽으로 희석될 수 있습니다. 화면에서 결측을 따로 표시합니다.
- 기본 점수 변경은 검토 단계입니다. 전체 채점 확정(C26)은 이 데모에서 조작하지 않습니다.
- 동일 입력 묶음의 해시로 반복 추가를 막습니다. 의미상 같은 다른 기사, 부분 실패 후 중복을 완전히 막는 설계는 아닙니다.
- 생성된 Excel은 재실행 전 닫아 주세요. 실행별 파일이므로 이전 시연 자료는 남습니다.
- 로컬 Host·Origin·변경 토큰 확인은 다중 사용자 인증이나 Prompt Injection 방어 검증을 대체하지 않습니다.
- 소요시간 절감, 외부 사용자 도입, 수익률, LLM 품질은 아직 측정하지 않았습니다.
